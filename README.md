# Falling Grid

A browser-based competitive block puzzle game built as a single HTML page.

**[▶ Play Falling Grid](https://daikiito-dk.github.io/falling-grid/)**

Open the link above and start playing immediately — no install or account required.

---

## 🎮 操作画面 / Controls

### PC / Mac

| キー | 操作 |
|---|---|
| `←` / `→` | 左右移動 |
| `↑` | 時計回りに回転 |
| `Z` | 反時計回りに回転 |
| `↓` | ソフトドロップ |
| `Space` | ハードドロップ |
| `C` / `Shift` | ホールド |
| `P` | 一時停止 |
| `R` | リスタート |

### 📱 スマホ

画面下部にタッチ操作ボタンが表示されます。

| ボタン | 操作 |
|---|---|
| `HOLD` | ピースをホールド |
| `↺` | 反時計回りに回転 |
| `↻` | 時計回りに回転 |
| `DROP` | ハードドロップ |
| `←` / `→` | 左右移動（長押し対応） |
| `↓` | ソフトドロップ（長押し対応） |

スマホではキーボード操作説明が自動的にタッチUIへ切り替わります。

## ✨ Features

- 10×20 playfield
- 7-piece bag randomizer
- SRS-style rotation and wall kicks
- Hold
- Ghost piece
- T-Spin detection
- Back-to-Back
- Combo scoring
- Web Audio sound effects
- Persistent personal best (top 10 scores via localStorage)
- Responsive dark UI
- Mobile touch controls

## 🏃 Play

**[▶ 今すぐプレイ](https://daikiito-dk.github.io/falling-grid/)**

The game runs directly in the browser. Your personal best is stored locally in your browser.

## 💻 Run locally

Open `index.html` in a modern browser.

```bash
open index.html
```

Or serve the repository with any static web server.

## 📱 Mobile

Falling Grid is designed to be playable on both desktop and mobile browsers. On small screens, touch controls replace the keyboard help panel and provide dedicated buttons for hold, rotation, hard drop, movement, and soft drop.
