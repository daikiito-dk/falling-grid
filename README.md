# Falling Grid

A browser-based competitive block puzzle game.

## Features

- 10×20 playfield
- 7-piece bag randomizer
- SRS-style rotation and wall kicks
- Hold
- Ghost piece
- T-Spin detection
- Back-to-Back
- Combo scoring
- Web Audio sound effects
- Persistent personal best (top 10 scores via localStorage)
- Responsive dark UI

## Run locally

Open `index.html` in a modern browser.

## Controls

- ← / →: Move
- ↑: Rotate clockwise
- Z: Rotate counter-clockwise
- ↓: Soft drop
- Space: Hard drop
- C / Shift: Hold
- P: Pause
- R: Restart
